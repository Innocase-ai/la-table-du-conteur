ALIGNEMENT AVEC LA FICHE GELÉE DU VIEUX PONT : pas de contradiction pour le sentier. Pont : « Par les vasières de la rive sud, un sentier de boue file vers l'ouest... jusqu'à l'excavation » (1 h, « carrière (ouest) ») ; carrière : « la rampe de l'est rejoint le sentier de la berge sud, qui file vers l'est par les vasières jusqu'au Vieux Pont, à une heure » ; retour « Depuis l'extrémité sud du pont, le sentier file vers l'ouest par les vasières, au bord de la berge sud ». Même durée, mêmes sens, mêmes mots (sentier de boue, berge sud, vasières). Seul le trajet vers l'auberge pose problème (voir correction n° 3).
